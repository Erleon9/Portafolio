# 🚀 Despliegue Rápido - Pasos Inmediatos

## Para Enviar el CV YA

### Opción 1: CV en PDF (Inmediato)
1. Abre `cv.html` en tu navegador
2. Presiona `Ctrl+P` (o `Cmd+P` en Mac)
3. Selecciona "Guardar como PDF"
4. ¡Ya tienes tu CV listo para enviar!

### Opción 2: Página Web en Vivo (5 minutos)

#### Paso 1: Instalar y Construir
```bash
cd "/Users/erosleon/Documents/Proyectos/Portafolio"
npm install
npm run build
```

#### Paso 2: Desplegar en Netlify
1. Ve a [netlify.com](https://netlify.com)
2. Regístrate gratis
3. Arrastra la carpeta `dist` al área de despliegue
4. ¡Listo! Tendrás una URL como: `https://amazing-name-123456.netlify.app`
