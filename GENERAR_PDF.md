# 📄 Generar PDF del CV - Guía Simple

## 🎯 **Método Recomendado (Inmediato)**

### **Paso 1: Abrir el CV**
```bash
# Abre el archivo cv.html en tu navegador
open cv.html
# O simplemente hacer doble clic en el archivo
```

### **Paso 2: Generar PDF**
1. **Ctrl+P** (o **Cmd+P** en Mac)
2. **Seleccionar "Guardar como PDF"**
3. **Configuración recomendada:**
   - Tamaño: A4
   - Márgenes: Mínimos
   - Opciones: ✅ Gráficos de fondo
   - Escala: 100%

### **Resultado:**
✅ PDF profesional con todos los logos visibles
✅ Optimizado para impresión
✅ Listo para enviar por email
